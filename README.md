# FEEDiT Presentation

FEEDiT 최종 발표용 독립 정적 사이트입니다.

## GitHub Pages

1. 발표 전용 저장소에 `index.html`과 `.nojekyll`을 업로드합니다.
2. Settings → Pages → Deploy from a branch를 선택합니다.
3. `main` / `/ (root)`를 선택하고 저장합니다.
4. 배포 완료 후 Settings → Pages에 표시되는 HTTPS 주소로 접속합니다.

저장소: `feedit-official/feedit-presentation`
발표 주소: `https://feedit-official.github.io/feedit-presentation/`

## 발표

- 방향키 / Enter / Space: 다음 단계
- M 또는 ㅡ: 목차
- F 또는 ㄹ: 전체화면
- 사진 클릭: 원본 확대
- 브랜드 필름: 무음 초기화 후 시작 위치에 일시정지합니다. 화질을 선택하고 영상 전체화면으로 전환한 뒤 재생하세요.
- 인터넷 연결이 필요합니다. 영상 화질은 YouTube 설정에서 선택합니다.

`index.html`에 발표 스크립트, 스타일, 이미지가 내장되어 있습니다.
별도 서버 프로그램이나 npm 설치 없이 GitHub Pages에서 제공할 수 있습니다.
수정할 때는 발표 작업 폴더에서 생성한 최신 `FEEDiT.html`을 `index.html`로 교체합니다.
